# Meissner Nordic Website

Marketing landing page for the **Meissner Nordic** mobile app - your companion for the Meissner Nordic Ski Area in Bend, Oregon.

## 🎿 About the App

Meissner Nordic provides real-time information for Nordic skiers:

- **Grooming Reports** - Live trail grooming status powered by Nordic Pulse
- **Weather Conditions** - Current weather and forecasts for the ski area
- **Interactive Trail Maps** - Explore trails with offline support
- **Events & News** - Stay updated on races and community activities
- **Webcams** - View live conditions on the mountain

## 🛠️ Development

Built with React, TypeScript, Vite, and Tailwind CSS.

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions on every push to `main`.
